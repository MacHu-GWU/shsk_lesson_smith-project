# 运行 rewrite-en-tutorial 把整门课重写成英文的输入

> 用法: 把 `<repo>` 全部换成教学仓库的绝对路径, 其余原样照发. 这一步在 examples 下全部 cn 版内容定稿之后跑, 整门课只跑这一次, 不要一个 mini task 跑一次.

/doc-writing-styles:rewrite-en-tutorial

把下面这些文件当作同一个系列一次性处理. 它们是一门课的全部教学内容, 互相引用, 术语与反复出现的小节标签必须跨篇统一. 为每份 `-cn.md` 产出去掉 `-cn` 后缀的同名英文版 (例如 `01-title/README-cn.md` 产出 `01-title/README.md`). 已有的英文版质量不佳, 无需留档, 直接覆盖.

```text
<repo>/examples/README-cn.md
<repo>/examples/*/README-cn.md
<repo>/examples/*/TICKET-cn.md
```

## 1. 这个仓库额外的硬约束

这个仓库有校验脚本 (`lesson-smith lint`), 下面几条不满足会直接报错, 请转达给每个写作者.

**YAML frontmatter 原样保形.** 每份 README 与 TICKET 顶部的 frontmatter 要保留, `description` 的值翻成英文, 但形态四条不能变: 保持一行 (不含换行), 值必须用双引号包起来, 值里不许出现任何引号类字符 (单引号, 双引号, 反引号), 英文后不超过 400 字符. 另外它原本是 1 到 2 句的一行摘要, 英文版保持同样的紧度, 不要展开成一段.

**H1 的字符集.** 每份文件的 H1 标题里, 除了字母, 数字, 逗号, 冒号, 句号以外不许有别的标点. 具体说, 不许出现连字符, 破折号, 引号, 双引号, 方括号, emoji. 英文标题很容易写成 `Getting Started: Branches, Merges and Conflicts` 这样是可以的, 但中间夹一个连字符或破折号就会报错.

**链接分两种, 处理方式相反.**

- 指向**文件**的相对路径链接一律换成英文版, 也就是去掉 `-cn` 后缀. 例如 `01-title/README-cn.md` 换成 `01-title/README.md`.
- 指向**目录**的相对路径链接原样不动. 不同语种的文件都落在同一个目录下, 目录名本身没有语种之分, 改了就成了死链. 例如 `./01-title/` 保持 `./01-title/`.

## 2. 不需要做的事

**不需要做本地化替换.** 这门课的中文版在创作时就已经用北美语境写了 (人名用 John Smith 一类, 公司产品场景取北美日常常见的). 里面不该有 `张三`, `双十一` 这类需要替换的东西. 如果确实撞见了, 按你自己的规则处理并在报告里说一声.

## 3. 不要做的事

不要把这批文件拆成多次调用. 跨篇的术语统一只在一次调用里成立.

不要加 `--no-reconcile`. 对账那一步抓的失败肉眼看不出来, 而这门课的英文版是要和中文版并排发布给学生的.
