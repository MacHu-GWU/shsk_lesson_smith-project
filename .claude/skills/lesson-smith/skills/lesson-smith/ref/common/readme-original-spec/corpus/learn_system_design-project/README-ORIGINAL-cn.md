# learn_system_design-project

System design 是把一句模糊的开放式需求推成一个能落地, 扛得住真实规模的方案的能力. 真实工程里的问题从来不干净: 需求含糊且一直在变, 你动的往往是一个已经在跑的系统, 每个决定都被成本, 工期和团队挤着. 面试把它单独拎出来考, 是因为它比算法更能看出一个工程师的判断力. 它属于那种短期拉不开差距, 长期却决定天花板的能力.

这门课带你把这件事练成肌肉记忆: 一条从澄清定界到画出架构的通用主线, 十道由浅入深的实战题把这条主线走满, 最后收束到面试与工程的方法论. 学完你能拿到一道没见过的题自己推下去: 澄清范围, 先建模再选组件, 在取舍中给出理由并扛得住追问. 深度对到 senior 与 staff 级别的面试和真实设计评审, 不是入门科普.

教法上不发标准答案让你背. 实战题用面试官和学生的对话加旁白还原一场真实面试, 配套的 agent 陪练让你读完立刻能练; 技术选型统一按 AWS 加主流开源讲, 例子取北美常见的消费级产品, 换一套技术栈这些判断依然成立. 课程本体在 [examples/README-cn.md](examples/README-cn.md), 从那里开始读.
