# learn_build_resume_matrix-project

Resume matrix 是把简历从一份静态文档变成一个可运营系统的做法: 一份长得离谱的 master resume 存住你全部的素材, 每次投递只从里面做减法, 派生出一份贴着那个岗位写的版本. 在 AI 时代这是刚需, 因为岗位边界越来越模糊, 同一个人往往同时够格投 Software Engineer, Data Analyst 和 AI Engineer, 而一份通用简历在任何一个方向上都不够锋利.

学完你能独立跑通这条链路: 拿到一份 JD 就能诊断出自己跟它的 gap, 把一段听起来很薄的实习或课程经历拔高到扛得住面试官追问, 压成经得起深挖的 bullets, 再从 bullets 反推出每个方向的 Summary, 最后派生出投递版本交出去. 深度是 advanced 档: 不是套模板, 而是能为简历上每一句话的取舍给出理由.

配套的十个 agent skill 把这条链路里最难的几步包下来, 从 gap 分析, 项目设计, 学习补强一直到模拟面试. 它们脱离课程也能单独用, 对任何一组 (case, JD) 都成立, 所以这门课学完留在你手上的不只是一份简历, 而是一套以后每换一次工作都能再跑一遍的工具.
