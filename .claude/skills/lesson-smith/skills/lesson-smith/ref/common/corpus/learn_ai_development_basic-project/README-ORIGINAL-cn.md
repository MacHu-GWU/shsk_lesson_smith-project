# learn_ai_development_basic-project

AI 应用开发已经从少数团队的实验, 变成了几乎每个软件岗位都会碰到的日常. 但真正的门槛不在模型本身, 而在模型之外那一层: 怎么让一次 API 调用的输出被下游代码稳定消费, 怎么把公司自己的资料喂给它, 怎么在需要的时候让它自己决定下一步做什么. 这一层是 AI engineering 的基本功, 也是这门课唯一要教的东西.

学完你能独立搭出一个属于自己的 AI 应用骨架: 接得上多家厂商的模型, 输出是结构化, 可校验的, 能基于你自己的文档回答问题, 也能自己调用工具完成多步任务. 深度是 basic 这一档, 目标是让你从"跟着 demo 抄"变成"知道每一层在干什么, 出了问题知道去哪找", 这是继续往 advanced 走的地基.

技术栈围绕 LangChain 和 Strands Agents, 但刻意不把框架当黑盒: 每个机制都先用裸 SDK 手写一遍, 再看框架替你省掉了什么. 所有内容都是可以直接 `uv run` 起来的 Python 脚本, 读一段, 跑一段, 改一段, 而不是读完一堆概念却什么也没跑起来.
