# learn_financial_engineer_interview-project

金融工程 (Financial Engineering), 业内更常叫 Quant, 坐在 finance, mathematics 和 technology 的交叉口. 定价模型, 风险系统, 交易策略是投行, 对冲基金和资管公司真正下注的地方, 也是这类岗位面试真正考的东西. 门票不好拿: 面试官问的从来不是定义, 而是你在一个具体场景里的判断力, 而这种判断力靠零散看书攒不出来.

这个 repo 是一套 264 道题的面试题库, 每道题都配一份完整的讲解文档, 按 Entry, Mid-Level, Senior 三档组织, 你照着目标职级挑深度即可. 走完之后, 面对一个陌生的模型问题, 你能说清它凭什么成立, 假设在哪里会断, 断了之后换什么工具. 这是 advanced 档的水平, 够撑一场正经的 Quant 面试, 也够你在入职后接住第一个真实项目.

用法有两种. 装了 Claude Code 就敲 `/practice-cn`, AI Agent 替你选题, 分面试模式和学习模式两种节奏带你过, 每题给反馈, 最后给一份得分与薄弱点清单. 不想用 Agent 也行, 题库本身就是普通的 Markdown, 从 `questions-index.md` 挑一道, 直接读那份讲解就是了.
