# learn_vercel_basic_v1-project

把一个网站送上互联网, 十年前是一件需要专人负责的事: 买服务器, 配环境, 开对端口, 申请证书还得记着续期, 写部署脚本, 出了事还要自己爬日志. Vercel 把这一整条链路收进了几次点击. 它今天是前端与全栈项目最常见的托管选择之一, 也是很多人第一次把自己的作品交到别人手上的地方.

这门课是 basic 档, 目标窄得刻意. 走完你会有一个真实的线上网站, 一条从改动到发布的完整链路, 以及出问题时自己去日志里取证据而不是瞎猜的习惯. 它不教你怎么写 app 代码, 教的是代码写完之后的那一段: 改一处, 推上去, 在隔离环境里看效果, 确认 Production 纹丝不动, 再合并发布. 这个循环转得多快, 就决定了你的项目推进得多快, 而这一点和项目有三行代码还是三万行无关.

课程刻意做得很小: 只讲平台本身, 三到四个小时能走完. 教程里的截图迟早会和你屏幕上看到的对不上, 但它们底下的逻辑不会变. 两者冲突时, 以 [Vercel 官方文档](https://vercel.com/docs) 为准.
