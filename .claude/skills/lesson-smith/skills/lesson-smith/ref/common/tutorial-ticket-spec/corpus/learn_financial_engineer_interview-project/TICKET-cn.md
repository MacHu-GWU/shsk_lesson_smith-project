# 用 AI 刷题定位知识盲区, 再把薄弱主题补到能讲清楚

## 1. 目标

这个题库有 264 道题, 分 E, M, H 三档难度, 覆盖 23 个主题, 从衍生品定价一路到低延迟计算. 你不需要, 也不可能全刷完. 这一趟要拿到的是另外两样东西: 一张你自己的知识盲区地图, 以及把其中最薄弱的那一两块补到能开口讲清楚的经验.

所以流程是固定的: 先随机测一轮当基线, 再按主题深挖, 隔天复测看有没有真进步. 随机出题这一步别跳, 自己挑题一定会挑软柿子, 那样测出来的地图是假的.

有一条红线要先说破: 这个题库不是用来背公式过面试的. 判断你学到没有的标准始终是, 你能不能用自己的话把一个概念讲给别人听, 以及你知不知道这个模型在什么条件下会失灵. 只会往公式里套数字, 面试官追问两句就穿帮了.

---

## 2. 要做的事情

1. 花 10 分钟翻一遍 questions-index.md, 对三档难度和 23 个主题有个地图, 知道自己接下来是在哪片地形里活动.
2. 按背景选起点难度: 刚接触量化金融从 E 开始, 有 1 到 2 年经验把 E 快速过一遍重点刷 M, 3 年以上直接上 M 和 H. 拿不准就把简历或项目经历粘给 Agent, 让它推荐难度和主题.
3. 在 Claude Code 里敲 /practice-cn, 选随机出题, 选面试模式, 把 3 道选择题加 3 道简答题全部答完, 把这一轮的得分和反馈记下来当基线.
4. 对着反馈把答错和只答对一半的题归到主题上, 挑出得分不到一半的 1 到 3 个主题作为优先项.
5. 再敲一次 /practice-cn, 这次选按主题随机, 挑一个优先主题, 切到学习模式, 一路追问到你能用自己的话把这个概念讲出来为止.
6. 隔至少一天, 用面试模式再测同一个主题, 和基线比一比. 间隔是有用的, 当天连着测只是在考短期记忆.
7. 补覆盖面: 挑 2 到 3 个还没碰过的主题各跑一轮, E, M, H 三档都要碰到, 别只在舒服的那一档里打转.
8. 挑一个你刚学明白的概念用 Python 实现一遍, Monte Carlo 定价或者 VaR 计算都行, 看它在真实数据上会在哪儿翻车.

**预计用时:** 每轮练习 20 到 30 分钟, 整条路径跨 3 到 5 天, 合计 3 到 4 小时

---

## 3. 检查清单

- [ ] **两种模式都跑过**: 面试模式和学习模式各至少跑过一轮, 你知道什么时候该从测试切到讲解.
- [ ] **基线还在**: 第一轮随机面试模式的得分和反馈你留下来了, 后面的进步有参照物可比.
- [ ] **点得出薄弱主题**: 你能具体说出 1 到 3 个得分最低的主题名字, 而不是笼统地说数学不行.
- [ ] **复测有进步**: 同一个主题隔天复测, 比基线至少多答对 1 到 2 题.
- [ ] **讲得清核心概念**: 不看笔记能讲清至少 3 个核心概念, 比如 Black-Scholes 的假设前提, VaR 的失效边界, delta hedging 靠什么成立.
- [ ] **说得出失效条件**: 对你深挖过的那个主题, 你能说出它的模型在什么条件下会失灵, 而不只是会套公式.
- [ ] **覆盖面铺开了**: 你至少碰过 E, M, H 三档各一题, 练过的主题不止起点那一个.
- [ ] **动手实现过一次**: 至少有一个概念被你用 Python 写出来跑过, 而不是只在题面上见过.
- [ ] **有下一步计划**: 手上有一份接下来练什么的计划, 具体到主题和难度, 不是继续刷.
