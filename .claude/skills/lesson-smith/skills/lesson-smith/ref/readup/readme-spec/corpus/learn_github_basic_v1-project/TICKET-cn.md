# 完成 Learn GitHub Basics 全部课程

## 1. 目标

读完本课程全部 mini task, 你要建立起对 GitHub 基础工作流的完整体感: 不再把它当成一堆零散的按钮, 而是一条能自己独立走完的主线, 从建 repo, 改文件, branch, PR, 到掌控访问权, 再到用 GitHub Desktop 在本地工作. 学完你应该能自信地说出 "这门课我学到了什么, 现在能独立做什么, 下一步往哪走".

---

## 2. 要做的事情

1. 先读根目录的 README, 明白这门课怎么读.
2. 读 examples 的系列索引, 对整门课有张地图.
3. 按编号顺序读完 examples 下全部 mini task, 每篇先读 README 再照它自己的 TICKET 逐项做完并确认. 前几篇都在你自己的同一个 repo 上叠加, 尽量按顺序读.
4. 读完最后那篇梳理与展望, 想清楚自己学到了什么, 以及下一步可以往哪走.

**预计用时:** 2.5 到 3 小时, 拆成几段来读也行.

---

## 3. 检查清单

- [ ] **全部 mini task 完成**: examples 下每个 task 的 TICKET 检查清单都已逐项打勾.
- [ ] **能独立复现**: 不看教程, 能把建 repo, 改文件, 开 branch, 用 PR 合并这套核心流程从头独立走一遍.
- [ ] **能讲清概念**: 能用自己的话解释 repository, branch, Pull Request, public 与 private, access token 各自解决什么问题.
- [ ] **本地工作流跑通**: 能用 GitHub Desktop 在本地完成 clone, commit, push, 分得清 local 和 remote 的边界.
- [ ] **认得清仓库归属**: 拿到一个仓库能说出它的 owner 是谁, 也知道去 organization 里找别人分享给你的仓库.

---

## 4. 关键能力

- 从零创建并配置一个 Repository, 并用匿名窗口验证它对外的可见性.
- 在网页端编辑文件, 并用一句有意义的 commit message 保存到 main.
- 用 branch 开辟平行分支安全地实验, 亲手体验分支隔离.
- 用 Pull Request 把分支成果 merge 回 main, 并理解 conflict 大致是怎么回事.
- 判断内容该 public 还是 private, 守住 secret 绝不进 public repo 这条安全红线.
- 用精确的 GitHub username 把 collaborator 邀请进来协作.
- 生成一个最小权限的 access token 并安全保存, 知道它随时可一键撤销.
- 用 GitHub Desktop 在本地完成 clone, commit, branch, push 与不走 PR 的本地 merge.
- 认清每个 repo 都挂在一个 owner 名下, 并能在 organization 的仓库列表里找到指定的仓库.
- 养成把一切工作都放上 GitHub 的习惯, 让 contribution graph 成为你最可信的长期记录.
