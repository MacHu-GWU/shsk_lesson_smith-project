# 收尾 Task 的 README 规范, 中文版

**适用范围**: `examples/` 下**最后那个 Task** 的 `README-cn.md`, 也就是收尾 Task 的教学正文. readup, upskill, showcase 三类都有这个 Task; evolve 没有 `examples/` 这一层, 不适用.

**位置是硬的, 名字是软的.** 它必须是编号最大的那一个, 排在全部特殊 Task 之后 (见 [01-repo-layout.md](../01-repo-layout.md) 第 4.2 节), 但目录名随课程而定. 没有任何工具需要按名字找到它, 所以不钉死. 代价是 lint 认不出它, 收尾 Task 缺席只能靠统稿那一步 (见 [08-series-converge-spec.md](../08-series-converge-spec.md) 第 3 节) 和人来发现.

**它是一个普通教学 Task**, 结构走通用的 [03-task-readme-spec](../03-task-readme-spec/task-readme-cn-spec.md). 本规范只补它**独有的那两件事** (回望与拔高), 其余一律以那一份为准.

**配套 TICKET 没有专属规范**, 直接走通用的 [04-task-ticket-spec](../04-task-ticket-spec/task-ticket-cn-spec.md). 索引 Task 之所以另有一份 TICKET 规范, 是因为它轻得反常需要专门交代; 收尾 Task 的 TICKET 是一份正常的 Task TICKET, 没什么可补的.

**配套骨架**: 无. 它的骨架就是通用 Task README 的骨架, 见 [task-readme-cn-template.md](../03-task-readme-spec/task-readme-cn-template.md).

**只管中文版**: 英文版另有一套, 属于多语种模块, 现在还没做.

---

## 1. 它是什么

整门课的最后一站. 学生走到这里, 该学的都学过了, 该证明的 (quiz) 该讲的 (demo) 也都做完了.

它干两件事, **缺一件就不成立**:

1. **回望**: 梳理这门课学了什么, 学完应该达到什么水平.
2. **拔高**: 如果还想更进一步, 往哪走.

**它不是索引的翻版.** 索引 Task 在开头画地图, 告诉你**将要**走哪条路; 收尾在结尾做总结, 说清你**已经**走完了什么, 手上多了什么. 两者海拔一样但时态不同, 写成同一份东西就浪费了一个 Task.

---

## 2. 回望怎么写

不是把各 Task 的标题重列一遍. 那是 SYLLABUS 的活, 而且学生刚读完, 不需要目录.

要写的是**读完之后才说得出口的那些话**:

- 这门课其实是围绕哪几件事展开的 (往往和 Task 的划分不是一一对应).
- 哪几个概念是真正的骨架, 忘了别的也不能忘它们.
- 一开始觉得难, 学完回头看其实是同一件事的那几处.
- 学到这里, 你手上具体多了什么能做的事.

对 upskill 与 showcase, 这一节要**提到 quiz 与 demo**: 学生刚做完那两件事, 收尾要把它们接住, 说清它们各自证明了什么.

---

## 3. 拔高怎么写

给的是**方向和入口**, 不是内容.

每个方向给两样东西, 都要能直接拿去用:

- **搜索关键字**: 学生复制粘贴进搜索引擎就能开始查的那几个词.
- **一句话话题**: 复制粘贴去喂给 AI 就能展开深挖的那一句.

**红线: 拔高只提, 决不能教.**

一旦为某个拔高方向单独展开写教程, 两件事同时发生: 它和这个 repo 的主线冲突 (学生分不清哪些是要学的, 哪些是选看的), 而且没完没了 (每个方向都能再展开一层). 真想教就把它变成一个正式的主线 Task, 走正常的编号和 TICKET, **不走拔高这个口子**.

判据很简单: 拔高那一节里如果出现了代码块, 步骤列表, 或者概念讲解, 就是越界了.

---

## 4. 什么时候写

**不是最后想起来才写的.** 它和索引 Task 一起, 在主线与全部特殊 Task 写完之后, 统稿之前补上 (创作工作流里 "回头补开头和结尾" 那一步).

**在特殊 Task 之后写, 是因为它得提到它们.** 收尾要说 "你现在应该能做到什么", 而 quiz 和 demo 正是证明这件事的两个动作, 它得在两者之后才说得出口.

---

## 5. 交付前自检

- 回望与拔高两件事都在, 没有只写一件
- 回望写的是读完才说得出口的话, 不是各 Task 标题的重列
- upskill 与 showcase: 回望里提到了 quiz (showcase 还要提 demo)
- 每个拔高方向都给了搜索关键字和一句话话题, 都能直接复制粘贴
- **拔高那一节里没有代码块, 没有步骤列表, 没有概念讲解**
- 其余 (三个区, H2 编号与分隔线, H1, frontmatter, 链接) 都过了通用 Task README 规范那一遍
