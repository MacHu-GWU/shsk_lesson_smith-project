## 2. 默认主线

故事走默认的七幕, 讲的是我如何用 AI 快速把一个技能学会并投入实战:

1. 发现某个技能值得投一周时间学会.
2. 让 AI 去把这个技能的权威资料翻出来.
3. 把这些资料蒸馏成一个专家 agent skill.
4. 让这个专家设计一份我一周能做完的大纲 (落成索引 Task).
5. 大纲每一个点都变成一个我能读又能上手练的例子 (落成各个教学 Task).
6. 在 AI 陪着的情况下把整门课刷完.
7. 把学会的技能用到一个真实问题上.
