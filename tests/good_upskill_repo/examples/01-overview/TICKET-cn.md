# 读懂这门课怎么走

## 1. 目标

这个 Task 就是读一遍索引, 拿到整门课的地图: 有哪些 Task, 它们怎么分组, 该按什么顺序走. 它没有产出物, 也没有要跑的命令, 所以别指望在这里学到技术细节, 真正的教学在后面每个 Task 自己的 README 里.

---

## 2. 要做的事情

1. 通读本 Task 的 README, 把这门课分成哪几块过一遍.
2. 按编号从下一个 Task 开始往后走, 每篇先读 README 再照它的 TICKET 做.

**预计用时:** 5 到 10 分钟

---

## 3. 检查清单

- [ ] **说得出分块**: 你能说出这门课分成哪几块, 每块解决什么.
- [ ] **说得出起点**: 你能说出自己打算从哪一块开始, 以及为什么.
