# GitHub 基础协作 系列索引

这门课教你在 GitHub 上完整走一次协作闭环: 建 repo, 用 commit 记录改动, 开 branch 隔离工作, 再通过 Pull Request 评审合并回 main. 全程在浏览器里完成, 不需要装任何东西. 下面的 Task 按编号排, 分成 4 块, 顺着读就行.

## 1. 打地基: repo 与 commit

先解决 "东西放哪, 改动怎么留痕" 这两件事.

- [02-create-repo](../02-create-repo/README-cn.md): 从零建一个 repository, 弄懂它和普通文件夹的区别.
- [03-edit-files](../03-edit-files/README-cn.md): 用网页编辑器改文件, 每次改动落成一个带 message 的 commit.

---

## 2. 协作主线: branch 与 Pull Request

这一块是整门课的核心, 也是真实团队每天都在转的轮子.

- [04-git-branch](../04-git-branch/README-cn.md): 开一条 branch, 把没写完的工作和稳定的 main 隔开.
- [05-merge-branch](../05-merge-branch/README-cn.md): 开 Pull Request 让人 review, 通过后合并回 main 并清理 branch.

---

## 3. 自测: 证明你真的懂了

这个 Task 不教新东西, 它只问你为什么.

- [06-prove-i-get-it](../06-prove-i-get-it/README-cn.md): 一套面试式自测题, 检验你对整门课是否知其然更知其所以然.

---

## 4. 收尾: 梳理与进阶

走完前面全部环节之后回望一次, 并挑一个继续深挖的方向.

- [07-level-up](../07-level-up/README-cn.md): 把整条闭环串成一句话, 确认自己达标, 并拿到进阶方向与搜索关键字.

---

## 5. 小结

前面几块串起来就是一条完整的协作闭环: 先有地方放代码, 再让每次改动留下痕迹, 然后学会把没写完的工作隔离出去, 最后把它评审着合并回来. 自测那一关会逼你说清每一步的为什么. 读完整条线, 你在 GitHub 上和别人协作时就不会再靠猜.
